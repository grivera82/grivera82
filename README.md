# Hi, I'm Jose Gabriel Rivera

I build plugins for [Omarchy](https://omarchy.org), the Arch Linux and Hyprland
setup. All nine below are MIT licensed and listed in the
[Omarchy plugin marketplace](https://plugins.omarchy.org/). Each one installs
with `omarchy plugin add <repo-url> --enable`.

## Omarchy plugins

- [**Agent Sessions**](https://github.com/grivera82/omarchy-agents): a bar widget
  that shows every running Claude Code, Codex, OpenCode and Grok session, which
  ones are waiting on you, token burn, plan limits and spend, and focuses the
  session's terminal on click.
- [**Jarvis**](https://github.com/grivera82/omarchy-jarvis): a voice assistant.
  Press the Copilot key to open apps, move windows, switch workspaces and play
  music. Speech runs locally, and other requests are planned by Claude or Codex.
- [**OmaPier**](https://github.com/grivera82/omapier): a glass dock with pinned
  apps, widgets (weather, AI agent limits, now playing, downloads, system
  graphs) and Dorito, an orange cat who lives on it.
- [**Matchday**](https://github.com/grivera82/omarchy-matchday): soccer scores,
  fixtures, standings and where to watch, for LaLiga, Serie A, Premier League,
  MLS, Nations League and Champions League.
- [**SpaceX Launches**](https://github.com/grivera82/omarchy-spacex): a T-minus
  countdown in the bar, the live flight timeline, launch alerts and the webcast
  in a picture-in-picture player.
- [**Airwaves**](https://github.com/grivera82/omarchy-airwaves): ad-free internet
  radio from SomaFM, Radio Paradise, NTS and FIP, with a visualizer in the bar.
- [**Kart Chaos**](https://github.com/grivera82/omarchy-kartchaos): a companion
  for the [Kart Chaos](https://kartchaos.com) browser racer, with the Daily
  Challenge, Time Trial records, online rooms and beaten-time alerts.
- [**Solitaire**](https://github.com/grivera82/omarchy-solitaire): a Klondike
  table with daily deals, drag and drop, keyboard play, hints, undo and saved
  games.
- [**Switchboard**](https://github.com/grivera82/omarchy-plugin-switchboard): a
  searchable menu for turning installed Omarchy plugins on and off without
  closing it.
